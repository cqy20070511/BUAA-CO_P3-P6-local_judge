# P4 加指令练习题目册

版本 2.0，2026-11-04。**本册共 14 题，每题均有确定的编码、操作、边界和示例，可在自己的 Verilog 单周期 CPU 上直接实现。** 每题从课下版本单独增加即可，也可累计实现。

题型参考 2020、2021、2023、2024 年课上记录。为补齐回忆缺失并避免跨年份冲突，本册重新分配部分编码，固定有争议的语义；**这些是练习用规定，不能当成官方原题编码。** 题源与差异见 [来源索引](../P4_历年课上题_来源索引.md)，原先未补全的历史资料移至 [文字回忆存档](../P4_历年课上题_文字回忆存档.md)。

配套：[P4 加指令练习包](./使用说明.md)。每题有独立的 `code.txt`、逐条反汇编、期望写入日志及比较脚本。自定义指令机器码已生成，无需先给 MARS 添加指令。

## 一、全部题目共用的规则

### CPU、存储与基础指令

- 32 位单周期 CPU，顶层为 `mips(input clk, input reset)`，**无延迟槽**。
- 基础指令为 `add, sub, ori, lui, lw, sw, beq, jal, jr, nop`。加减取低 32 位，不产生溢出异常。
- PC、GRF、DM **同步复位**：reset=1 的上升沿将 PC 置为 `0x00003000`，GRF 和 DM 全清零。reset=0 时执行当前指令。
- $0 恒为 0，写 $0 不改变状态、不打印寄存器写入日志。其他明确“不写”的情况必须禁止写入，不能用写回旧值代替。
- IM 为 4096×32，指令字节地址 `0x3000～0x6ffc`，索引为 `(PC-0x3000)>>2`。复位不清除已加载的指令。
- DM 为 3072×32，字节地址 `0x0000～0x2fff`。采用小端序：字 `0x12345678` 在低地址到高地址的字节依次为 `78,56,34,12`。
- 只要求处理本册合法编码和有效地址；不要求处理异常。普通 lw/sw 地址四字节对齐，各扩展指令按自己的地址规则执行。

### 符号与执行顺序

| 记号 | 定义 |
|---|---|
| P | 当前指令执行前的 PC |
| R[i] | 执行前第 i 个寄存器值；单独的 rs/rt/rd 是编号 |
| SE16(imm) | 16 位立即数符号扩展到 32 位 |
| B(imm) | `SE18({imm[15:0],2'b00})`，先拼 18 位再符号扩展；等价于 `SE16(imm)<<2` 后取低 32 位 |
| Mem32[A] | 字节地址 A 处的字，A 是 4 的倍数 |
| Mem16[A]、Mem8[A] | 小端半字、字节；半字地址是 2 的倍数 |
| align4(A) | `A & 0xfffffffc` |
| pop(x) | 全部 32 位中 1 的个数，范围 0～32 |
| ctz(x) | 从 bit0 向高位连续 0 的个数，**ctz(0)=32** |
| ROR(x,n) | 32 位循环右移 n 位，ROR(x,0)=x |

先用全部**旧值**算出条件、源数据和地址，再同时提交写入与 nextPC。源、目的寄存器相同也遵守此规则。未另行说明时 nextPC=P+4；不写内存、不改其他寄存器。PC/地址加法、数据加减均取低 32 位。

### 写入日志

实际写入非零号寄存器时输出 `@PC: $编号 <= 数据`；存储时输出 `@PC: *字对齐地址 <= 存储后完整字`。PC、地址、数据均为八位十六进制，寄存器编号为十进制。允许时间前缀。

Q06 的字节存储也打印合并后的完整字。条件失败且“不写回”时没有日志；Q14 失败会写 0，因此仍有日志。比较脚本检查写入事件的顺序、PC、目标和值。

## 二、编码速查

R 型从 bit31 到 bit0：`op6 rs5 rt5 rd5 shamt5 funct6`。I 型：`op6 rs5 rt5 imm16`。固定字段必须使用表中的值。I 型没有 funct 字段。

| 题号 | 指令及汇编操作数顺序 | op（二进制 / hex） | funct（二进制 / hex） | 完整 32 位格式 |
|---|---|---|---|---|
| Q01 | `eam rd, rs, rt` | `000000 / 00` | `110000 / 30` | `000000 rs rt rd 00000 110000` |
| Q02 | `cptl rs, rt, offset` | `110000 / 30` | 不适用 | `110000 rs rt offset16` |
| Q03 | `olw rt, offset(base)` | `110001 / 31` | 不适用 | `110001 base rt offset16` |
| Q04 | `hmo rd, rs, rt` | `000000 / 00` | `110001 / 31` | `000000 rs rt rd 00000 110001` |
| Q05 | `bnoal rs, rt, offset` | `110010 / 32` | 不适用 | `110010 rs rt offset16` |
| Q06 | `sgray rt, offset(base)` | `110011 / 33` | 不适用 | `110011 base rt offset16` |
| Q07 | `rlb rt, rs, imm` | `110100 / 34` | 不适用 | `110100 rs rt imm16` |
| Q08 | `bnezalc rs, offset` | `000001 / 01` | 不适用 | `000001 rs 10011 offset16` |
| Q09 | `lwrr rt, offset(base)` | `110101 / 35` | 不适用 | `110101 base rt offset16` |
| Q10 | `bsoal rs, offset` | `110110 / 36` | 不适用 | `110110 rs 00000 offset16` |
| Q11 | `xor rd, rs, rt` | `000000 / 00` | `100110 / 26` | `000000 rs rt rd 00000 100110` |
| Q12 | `swrr rt, offset(base)` | `110111 / 37` | 不适用 | `110111 base rt offset16` |
| Q13 | `bszeal rs, rt, offset` | `111000 / 38` | 不适用 | `111000 rs rt offset16` |
| Q14 | `lha rt, offset(base)` | `111001 / 39` | 不适用 | `111001 base rt offset16` |

Q05、Q06 的助记符由本册命名。Q08 的 `10011` 是子操作码，不代表读取 $19。未使用的编码不要求支持。Controller 内部的 type、ALUOp 可自行分配，不必等于 op/funct。

## 三、逐题定义

### Q01　eam：有符号取模与条件扩展

编码：`000000 rs rt rd 00000 110000`。

```text
x = 将 R[rs][15:0] 解释为16位补码有符号数
t = x 对17的非负余数，0 <= t <= 16
if R[rt][31] == 1:
    R[rd] <- {16'h0000, t的16位表示}
else:
    R[rd] <- {16'hffff, t的16位表示}
nextPC <- P + 4
```

例：R[1]=`0x0000ffff`、R[2]=`0x80000000`，`eam $3,$1,$2` 写入 `0x00000010`；若 R[2]=0，则写入 `0xffff0010`。

边界：x=0、17、-17 时 t=0，x=-1 时 t=16。一扩展固定补 1，不是符号扩展。本册固定采用回忆文字的版本 A；相反的扩展方向不适用于此练习。

### Q02　cptl：总是分支，条件选择链接目标

编码：`110000 rs rt offset16`。

```text
c = 存在 i∈[0,12]，使 R[rs][i+5:i] == 6'b111111
if c: R[rt] <- P + 4
else: R[31] <- P + 4
nextPC <- P + 4 + B(offset)
```

例：P=`0x3000`、R[1]=`0x3f`，`cptl $1,$7,2` 写 R[7]=`0x3004`、跳至 `0x300c`。R[1]=`0x1f` 时改写 $31，跳转目标相同。

边界：只查低 18 位的 13 个窗口，窗口可重叠。六个 1 完全位于 bit23～18 不成立。rt=0 且条件为真时丢弃链接；rs=rt 时先用旧值判断。offset 可为负或 0，无延迟槽。

### Q03　olw：满足 0*1* 位模式时加载

编码：`110001 base rt offset16`。

```text
EA = R[base] + B(offset)
d = Mem32[EA]
c = d 从bit31到bit0具有“若干0后接若干1”的形式
if c: R[rt] <- d
else: 不写任何寄存器
nextPC <- P + 4
```

保证 EA 四字节对齐且在 `0～0x2ffc`。本题偏移为 **B(offset)**，不是普通 lw 的 SE16(offset)。

例：R[1]=`0x20`、offset=2，读地址 `0x28`。字为 `0x00000007` 时写回；为 `0x00000005` 时不写、无日志。

边界：0、`0xffffffff` 均满足条件；0 段或 1 段可为空。等价判断为 `(d & (d+1)) == 0`，d+1 按 32 位回绕。读出的内存数据参与 GRF 写使能判断。

### Q04　hmo：按 1 的个数选择寄存器编号

编码：`000000 rs rt rd 00000 110001`。

```text
if pop(R[rs]) > pop(R[rt]): R[rd] <- rs编号零扩展到32位
else: R[rd] <- rt编号零扩展到32位
nextPC <- P + 4
```

例：rs=4、rt=9、rd=3，R[4]=7、R[9]=`0x80000000`，R[3]=4；若 R[9]=`0x0b`，双方均有三个 1，R[3]=9。

边界：相等时选 rt，计数含全部 32 位，写入的是编号，结果范围 0～31。rd 与任一源重合时仍比较旧值。

### Q05　bnoal：有符号加法不溢出时分支并链接

编码：`110010 rs rt offset16`。这是对 2023 年缺失名称、溢出条件记录的**练习改编**；固定检查加法。

```text
a = signed32(R[rs]); b = signed32(R[rt])
s = a+b，先按数学整数计算
c = -2147483648 <= s <= 2147483647
if c:
    R[31] <- P + 4
    nextPC <- P + 4 + B(offset)
else:
    不写任何寄存器
    nextPC <- P + 4
```

例：P=`0x3000`、R[1]=`0x7fffffff`、R[2]=1、offset=2，溢出，不跳、不链接。R[1]=`0xffffffff`、R[2]=1 时和为 0，不溢出，$31=`0x3004`、目标=`0x300c`。

边界：负数加负数也可能溢出；异号相加不溢出。和本身不写回，不触发异常。源编号为 31 时，先读旧 $31 再链接。

### Q06　sgray：分组格雷码条件字节存储

编码：`110011 base rt offset16`。这是对 2023 年缺失名称及错误切片记录的**练习改编**。

定义 g8(b)：把字节分成四个互不交叉的二位组，各组按 `00→00、01→01、10→11、11→10` 转换，保持组的位置。

```text
EA = R[base] + SE16(offset)
k = EA[1:0]
m = 旧 Mem8[EA]
for j=0..3: t[j] = g8(R[rt][8*j+7:8*j])
if m等于t[0]、t[1]、t[2]、t[3]中至少一个:
    Mem8[EA] <- t[k]
else:
    Mem8[EA] <- 8'hff
nextPC <- P + 4
```

EA 可为任意有效字节地址。**只改目标字节，另外三个旧字节保持。** 日志为 align4(EA) 和合并后的完整字。

例：R[rt]=`0x03020100`，t[0..3]=`00,01,03,02`。旧 Mem32[0]=`0x44332200`、EA=1，目标旧字节 0x22 无匹配，结果=`0x4433ff00`。旧字为 `0x44330300` 时，0x03 有匹配，写 t[1]=0x01，结果=`0x44330100`。

边界：可匹配任一候选，不要求匹配 t[k]。转换和比较都取旧值。不是对整字节统一执行一次 `b^(b>>1)`，二位组之间不互相影响。不写 GRF。

### Q07　rlb：低 imm 位按位取反

编码：`110100 rs rt imm16`，保证 imm 为 0～31 的无符号整数。

```text
mask = (2^imm)-1，作为32位数；imm=0时mask=0
R[rt] <- R[rs] XOR mask
nextPC <- P + 4
```

例：R[1]=`0x12345678`，`rlb $2,$1,4` 得 `0x12345677`。imm=0 原样复制；imm=31、源为 0 时结果=`0x7fffffff`。

高 32−imm 位保持。这是按位取反，不是位序逆转。rs=rt 合法，rt=0 丢弃写入。

### Q08　bnezalc：非零时分支并链接

编码：`000001 rs 10011 offset16`。

```text
if R[rs] != 0:
    R[31] <- P + 4
    nextPC <- P + 4 + B(offset)
else:
    不写任何寄存器
    nextPC <- P + 4
```

例：P=`0x3000`、R[1]=1、offset=2，写 $31=`0x3004`、跳至 `0x300c`；源为 0 时顺序执行，$31 保持。

边界：正数、负数都属于非零。无延迟槽，链接值为 P+4。rs=31 用旧值判断。固定子操作码 `10011` 必须参与译码。

### Q09　lwrr：加载包含字并按字节循环右移

编码：`110101 base rt offset16`。

```text
EA = R[base] + SE16(offset)
k = EA[1:0]
d = Mem32[align4(EA)]
R[rt] <- ROR(d,8*k)
nextPC <- P + 4
```

EA 可不对齐，包含字必须在有效 DM 范围。例：d=`0x12345678`，k=0、1、2、3 时，结果依次是 `12345678、78123456、56781234、34567812`。

边界：只读一个包含字后旋转，不跨字读取；k=0 不移位。rt=base 先用旧值算地址。不写内存。

### Q10　bsoal：1 的个数为奇数时分支并链接

编码：`110110 rs 00000 offset16`。

```text
if pop(R[rs]) mod 2 == 1:
    R[31] <- P + 4
    nextPC <- P + 4 + B(offset)
else:
    不写任何寄存器
    nextPC <- P + 4
```

例：源为 8，有一个 1，成立；源为 5，有两个 1，不成立。P=`0x3000`、offset=2、成立时，$31=`0x3004`、目标=`0x300c`。

边界：0 有零个 1，全 1 有 32 个 1，均不跳、不链接。判断的是 1 的个数，不是数值奇偶。rt 字段固定为 0。

### Q11　xor：按位异或

编码：`000000 rs rt rd 00000 100110`。

```text
R[rd] <- R[rs] XOR R[rt]
nextPC <- P + 4
```

例：`0x0000f0f0 XOR 0x00003333 = 0x0000c3c3`。任意 x 与自己异或为 0，与 0 异或为 x。rd=rs、rd=rt、rd=0 均合法。不修改内存。

### Q12　swrr：按地址低位旋转后存储完整字

编码：`110111 base rt offset16`。

```text
EA = R[base] + SE16(offset)
k = EA[1:0]
Mem32[align4(EA)] <- ROR(R[rt],8*k)
nextPC <- P + 4
```

例：R[rt]=`0x12345678`、EA=5，向字节地址 4 写入完整字 `0x78123456`，日志地址为 `00000004`。

边界：整字覆盖，不是部分写；k=0 等价于对齐 sw。base=rt 用同一个旧值算地址和存储数据。不写 GRF。

### Q13　bszeal：后导零相等则分支，总是链接

编码：`111000 rs rt offset16`。

```text
a = ctz(R[rs]); b = ctz(R[rt])，ctz(0)=32
R[31] <- P + 4                     // 无论条件是否成立
if a == b: nextPC <- P + 4 + B(offset)
else: nextPC <- P + 4
```

例：P=`0x3000`，源为 10 和 12，计数为 1、2，不跳但仍写 $31=`0x3004`；源为 20 和 12，计数均为 2，offset=2 时跳至 `0x300c`。

边界：0 与 0 相等；0 与 `0x80000000` 的计数为 32、31，不等。源可为 31，读取旧值。链接目标固定 $31、数据固定 P+4，为本册补齐的练习规则。

### Q14　lha：半字为 4 的倍数时加载，否则写 0

编码：`111001 base rt offset16`，本册统一拼写 lha。

```text
EA = R[base] + SE16(offset)
h = Mem16[EA]
if h[1:0] == 2'b00: R[rt] <- h符号扩展到32位
else: R[rt] <- 32'h00000000
nextPC <- P + 4
```

保证 EA 为偶数且在 `0～0x2ffe`。例：旧 Mem32[0]=`0x0006fffc`，EA=0 写回 `0xfffffffc`，EA=2 写回 0。

边界：0、`0x8000`、`0xfffc` 均满足倍数条件，`0xffff` 不满足。按半字 bit15 符号扩展。条件失败仍写 0，rt=0 时才丢弃写入。

## 四、建议顺序

1. Q11、Q07、Q04：译码、ALU 与寄存器编号。
2. Q08、Q10、Q05、Q13：分支、链接、条件写使能。
3. Q09、Q12、Q14：对齐、字节选择与符号扩展。
4. Q01、Q02、Q03、Q06：复杂组合逻辑，以及 DM 数据对控制信号的反馈。

每题先跑 basic，再跑 edges、alias_zero。每个程序只依赖基础指令和本题，不要求先实现其他题。通过配套测试表示覆盖到的输入正确，不表示穷尽所有可能情况。
