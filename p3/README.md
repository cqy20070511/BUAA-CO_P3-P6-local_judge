# P3 加指令练习包

先读 [题目册](题目册.md)，它给出了 25 条指令的确定编码和行为。每题可以独立完成，也可以逐步累计到同一份 CPU 中。

## 你发电路给我时

告诉我题号即可，例如：“检查 E05 wsbh，文件是 CPU_wsbh.circ”。我会使用本包固定的编码、测试程序和期望值检查；若累计完成多题，可写“检查 E05、E12、E20”。不需要重新描述题意。

建议每题另存一份电路，并保留一份通过原八条指令测试的备份。

## 自己运行评测

双击 **开始评测.cmd**，选择电路、勾选已完成题目，点击“开始评测”。需要本机已安装 Java 8 或更高版本；本包已附带 Logisim 仿真引擎和编译好的评测程序，不需要启动 Logisim 窗口或安装 Python。

命令行也可以运行：

```powershell
.\开始评测.cmd "C:\Users\陈清扬\Desktop\CPU.circ" "E05,E12,E20"
```

`BASE` 是原八条指令和复位回归检查；`all` 仅用于已实现全部 25 题的电路。每次只评测选中的题，不会把尚未实现的题算成错误。

## 文件内容

- `题目册.md`：完整题面、六位 OP/FUN 表、32 位格式、边界规则和题型来源。
- `instructions.json / instructions.tsv`：可供工具读取的指令规格。
- `tests/E题号/用例名/`：每题的自动测试；共 283 组、23,268 个预定执行周期（包含 BASE）。
- `program.hex`：可直接加载 ROM 的 `v2.0 raw` 文件。
- `program.asm`：正常的 MIPS/练习指令助记符，含地址标签；配套 MARS 汇编适配器可以识别本册新增指令。
- `listing.txt`：PC、十六进制、**32 位二进制**和源指令字段。
- `expected.tsv`：逐周期的八信号有效期望、nextPC 以及执行后 GRF/DM 的 SHA-256。
- `practice.jar / lib/`：本地真实 Logisim 仿真评测器。
- `src/`：测试生成器、独立参考模型和评测器源码。

自定义指令无法直接由原版 MARS 识别。本包的 MARS 汇编适配器会安装本册的 25 条编码规则，用真正的 MARS 汇编源码并导出机器码；283 组源码的汇编结果已经与生成器逐字比较。适配器只负责汇编，不冒充 MARS 的新指令执行器。

期望值由 Python 参考模型生成，再以独立 Java 模型逐周期核对，两者一致后才运行电路。`listing.txt` 中的 rs/rt/rd 字段表示编号。

如果你自己写了使用本册指令的汇编文件，也可以导出 ROM 镜像：

```powershell
java '-Dfile.encoding=UTF-8' -cp '.\practice.jar;.\lib\*' MarsExport '.' '自己的程序.asm' '自己的程序.hex'
```

这条命令仅汇编导出；本地一键评测使用包内已经准备好的测试程序和期望。

查看判定细节、接口约定及报告解释，请读 [评测说明](评测说明.md)。
