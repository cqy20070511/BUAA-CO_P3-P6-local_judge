# 评测说明

## 电路接口

使用原课程接口即可，不要求增加任何用于评测的端口：

| 端口 | 位宽 | 方向 |
|---|---|---|
| reset | 1 | 输入 |
| Instr | 32 | 输出 |
| pc | 32 | 输出 |
| RegWrite | 1 | 输出 |
| RegAddr | 5 | 输出 |
| RegData | 32 | 输出 |
| MemWrite | 1 | 输出 |
| MemAddr | 32 | 输出 |
| MemData | 32 | 输出 |

顶层名 `main`，包含一个内置 Clock；IM 为 4096×32 的 ROM。内部状态识别沿用已经在你 CPU 上使用的适配方式：GRF 为 31/32 个 32 位 Register，并有 A1/A2、RD1/RD2；PC 为独立子模块里的寄存器；DM 为 32 位 RAM，可物理配置为 4096 字，但课程有效范围为前 3072 字。

若你重构了模块导致存储映射无法识别，会报告 ERROR/适配失败，不会将其当作实现正确，也不会直接判为指令语义 WA。可以把电路发给我调整适配。多个满足尺寸的 ROM 可通过 Java 命令的 `--rom 子电路名或ROM标签` 指定。

字节加载指令 E20/E24/E25 的顶层 MemAddr 应输出完整字节地址 EA；内部 RAM 的字索引由 EA 去掉低两位获得。E19 lwor 的顶层 MemAddr 应为最终加法和掩码后的 EA。E22 jas 的 MemAddr=旧 R[29]，MemData=PC+4。

## 一次评测做什么

1. 读取测试机器码和提前生成的期望；Java 独立执行模型校验 Python 期望，包括每一步完整 GRF/DM 状态摘要。期望有矛盾会报告工具错误。发布前还用带本册编码扩展的 MARS 实际汇编了全部 283 份源码，并与预生成机器码逐字比较。
2. 将机器码载入仿真中的 ROM，执行真实异步 reset；不改原始 `.circ` 文件。结果目录保留原文件快照和带测试 ROM 的副本。
3. 每个周期先检查当前指令的有效控制/地址/数据，再推进真实 Clock 到上升沿，检查实际 PC、GRF、DM、IM。状态检查包括未被本题使用的寄存器和内存，能发现意外写入。
4. 输出每次采样的八个信号和压缩的完整存储轨迹。关闭写入时的无效数据总线不强制为 0；字节加载也检查未覆盖字节是否保持。
5. BASE 中另测 reset 在时钟低电平、高电平和跨上升沿保持时的异步效果，复位后执行首条指令确认能重新启动。

自跳转等循环题采用题目预设的有限执行窗口，逐周期验证后结束；这是刻意的有界测试，不靠超时判断成功。每题包含几组还是几十组取决于分支、地址和目标编号的组合数量。

## 报告

结果保存在 `results/每次运行目录/`，主要文件为：

- `report.html`：总报告，可在浏览器直接打开。
- `检查报告.md / results.csv`：通过和失败列表。
- `storage_map.csv`：实际寄存器、PC 和内存的识别路径。
- 每个用例的 `failure.txt`：题号、周期、PC、机器码、当前指令及第一个不一致信号/存储位置。
- `failure_state.csv`：失败采样时全部物理存储位置的实际值与期望值。
- `signals.csv`：执行前、执行后的八信号。执行后的组合输出属于下一条指令，不能当成上一条指令的写回。
- `state.p3trace.gz`：存储元件的无损增量轨迹，供进一步定位。
- `CPU_loaded.circ`：带相应用例 ROM 的副本，可以在 Logisim 打开复现；不要把它误当成原电路被修改。

每个用例仅在全部预定周期和相应复位检查完成后才能 PASS。退出码 0=通过，1=电路行为不一致，2=工具/输入/适配错误。通过这些用例表示在本包覆盖范围内行为正确，不保证覆盖所有可能输入。

## 手工复现

打开你保存的电路副本，在 IM 的 ROM 右键选择 Load Image，加载相应用例的 `program.hex`，reset 一次，再按周期推进。用 `listing.txt` 和 `expected.tsv` 查看当前 PC 的预期结果。

开始前不要预置寄存器或内存；测试程序自己用原八条指令建立初始数据。程序最长不超过 1024 条，地址有效；不会偷偷使用 addi、j 等未要求的辅助指令。

## 可复现性与工具自检

生成器使用固定随机种子 `20261029`。`checksums.json` 记录测试文件摘要。

```powershell
java '-Dfile.encoding=UTF-8' -cp '.\practice.jar;.\lib\*' PracticeRunner --self-test
java '-Dfile.encoding=UTF-8' -cp '.\practice.jar;.\lib\*' PracticeRunner --cpu 'CPU.circ' --exercise 'E05,E20'
java '-Dfile.encoding=UTF-8' -cp '.\practice.jar;.\lib\*' MarsExport '.'
```

第三条命令重新检查所有源码的 MARS 汇编结果。上述自检不等于你的 CPU 通过测试。完整评测记录另见 `工具验证记录.md`。
